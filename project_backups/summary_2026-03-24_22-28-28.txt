Task: Milestone 1 - lesson completion and course progress

Prisma models added/modified:
- Added LessonCompletion model with fields: id, user_id, lesson_id, course_id, createdAt.
- Added relations from User -> LessonCompletion[], Course -> LessonCompletion[], and Lesson -> LessonCompletion[].
- Added unique constraint on [user_id, lesson_id] and indexes on user_id, course_id, and [user_id, course_id].

New functions, APIs, and routes:
- Backend CoursesService:
  - Added completeLesson(user, courseId, lessonId) to mark a lesson complete for an enrolled student.
  - Added shared course progress calculation helpers for total/completed lessons and percentage.
  - Updated getOne(user, id) to return student lesson completion state per lesson and top-level course progress.
  - Updated getAllByTenant(user, query) for students to attach per-course progress summaries for enrolled courses.
- Backend CoursesController:
  - Added POST /api/courses/:courseId/lessons/:lessonId/complete for student lesson completion.
- Backend EnrollmentsService:
  - Updated myCourses(user) to return progress summary for each enrolled course.
- Frontend course details page:
  - Added course progress summary card.
  - Added lesson completion buttons for students.
  - Added React Query mutation to call POST /api/courses/:courseId/lessons/:lessonId/complete.
  - Added invalidation so course progress refreshes immediately in course view, dashboard, and my-courses.
- Frontend dashboard:
  - Extended dashboard course types with progress data.
  - Updated student dashboard course cards to show progress bars and completed lesson counts.
- Frontend my-courses page:
  - Added course progress bars for enrolled courses.
- Backend tests:
  - Added coverage for lesson completion creation and progress calculation in courses.service.spec.ts.

Migrations / schema changes:
- Prisma schema updated with the new LessonCompletion model and relations.
- Database synced with prisma db push --accept-data-loss.
- Prisma client regenerated.
