Instapay validation rules implemented:
- Option 1: Phone
  - must start with 010, 011, or 012
  - enforced with regex: ^01[012]\d{8}$
- Option 2: Username
  - must end with @instapay
  - invalid domains like gmail.com are rejected
  - enforced with regex: ^[a-z0-9._-]+@instapay$
- Invalid formats are rejected by the backend with a specific BadRequestException message.
- The same validation rules are enforced on the frontend before submit so instructors see immediate validation feedback.
