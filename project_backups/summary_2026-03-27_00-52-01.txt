Implemented the instructor-only subscription and 7-day trial system at the tenant/workspace level.

Prisma schema changes:
- Added enum `SubscriptionState` with `TRIAL`, `ACTIVE`, `EXPIRED`, `CANCELED`.
- Added enum `BillingPeriod` with `MONTHLY`, `YEARLY`.
- Expanded `Plan` with pricing, archive/core flags, and the fixed permission catalog:
  - `monthlyPrice`, `yearlyPrice`
  - `maxCourses`, `maxSectionsPerCourse`, `maxLessonsPerSection`
  - `canPublishCourses`, `canCreatePaidCourses`
  - `maxStudentsTotal`, `maxStudentsPerCourse`
  - `canUseQuizzes`, `canUseAssignments`, `canIssueCertificates`
  - `canUseAnalytics`, `canUseReviews`
  - `maxStorageMb`, `canUploadThumbnails`, `canUploadProfileImage`
  - `canUseManualPayments`, `hasAdvancedAnalytics`, `hasOnlinePayments`
  - `maxAdminUsers`, `maxInstructorUsers`
  - `isCore`, `isArchived`
- Added `TenantSubscription` model for real subscription history and state tracking.
- Extended `Tenant` with `subscriptions` relation while keeping `planId` as the selected/current plan pointer.

Backend module and API changes:
- Added `SubscriptionsModule` with:
  - `GET /api/subscription/me`
  - `GET /api/subscription/plans`
  - `POST /api/subscription/select-plan`
  - `GET /api/subscription/tenants/:id`
  - `POST /api/subscription/tenants/:id`
  - `PATCH /api/subscription/tenants/:id`
- Added subscription DTOs for instructor plan selection and admin subscription management.
- `SubscriptionsService` now:
  - seeds the four core plans: `Launch`, `Studio`, `Growth`, `Empire`
  - applies the global 7-day trial rule set
  - starts trials only after plan selection
  - creates active monthly/yearly admin-managed subscriptions
  - expires stale subscriptions automatically on read
  - exposes instructor subscription summaries and admin tenant subscription summaries
  - enforces tenant student-cap growth
- `PlansService` was refactored to the expanded plan schema and now supports:
  - listing plans with counts
  - creating plans with the fixed permission catalog
  - updating plans
  - archiving plans
  - tenant usage aggregation
- Admin APIs were updated to match the new subscription model:
  - `PATCH /api/admin/plans/:id/archive`
  - tenant detail now includes subscription data from `SubscriptionsService`
- Removed the old default-plan bootstrap behavior for new instructor tenants.

Backend enforcement and business-rule changes:
- Instructor registration still creates the tenant/workspace, but no subscription is auto-activated.
- Student registration and student-instructor joins now enforce workspace student caps via `SubscriptionsService` instead of the old plan-limit helper.
- Subscription/trial limits are now enforced in backend business logic for:
  - course creation/update/status changes
  - course thumbnail upload
  - section creation/update/remove/reorder
  - lesson creation/update/remove/reorder
  - quiz creation
  - assignment creation and review
  - certificate issuance
  - instructor analytics access
  - instructor payment-method creation
  - instructor profile-image upload
- Trial/freeze behavior now blocks instructor creation/editing flows when no active trial/subscription exists.
- Trial rules currently enforced:
  - max 2 courses
  - max 1 section per course
  - max 1 lesson per section
  - free courses only
  - max 10 students total in the workspace

Frontend changes:
- Added instructor subscription selection page:
  - `apps/frontend/src/app/subscription/page.tsx`
- Updated registration flow so new instructors are redirected to `/subscription` immediately after account creation.
- Updated middleware to protect `/subscription` for instructors only.
- Updated dashboard so instructors:
  - fetch subscription summary from `/subscription/me`
  - are redirected to `/subscription` if they still need to choose a plan
  - see a clear banner for trial/active/frozen subscription state
- Updated admin dashboard to support the new model:
  - plan type/form expanded to the fixed permission catalog and monthly/yearly pricing
  - plan archive action
  - tenant detail now shows subscription state, trial remaining days, freeze state, and current limits
  - tenant subscription controls now activate monthly/yearly plans, restart trial, and end current subscriptions through `/api/subscription/tenants/:id`
