Phase 1 Completion Summary

Prisma models added/modified:
- Added enum `AssignmentSubmissionStatus` with `PENDING_REVIEW` and `REVIEWED`.
- Modified `AssignmentSubmission` model to add:
  - `status`
  - `feedback`
  - `score`
  - `reviewedAt`
- Added `CourseLearnerState` model to track student continuity state per course:
  - `id`
  - `userId`
  - `courseId`
  - `lastLessonId`
  - `updatedAt`
- Added new relations:
  - `User.learnerStates`
  - `Course.learnerStates`
  - `Lesson.learnerStates` via `LastViewedLesson`

Backend functions, APIs, and routes added/updated:
- Assessments:
  - Added DTO `ReviewAssignmentSubmissionDto`.
  - Updated `AssessmentsService` to support:
    - instructor assignment review
    - returning student submission review state/feedback/score
    - resetting review state when a student resubmits an assignment
  - Added routes:
    - `GET /api/assessments/courses/:courseId/assignment-submissions`
    - `PATCH /api/assessments/assignments/:assignmentId/submissions/:submissionId/review`
- Courses:
  - Added learner management and continuity methods in `CoursesService`:
    - `getCourseLearners`
    - `getContinueLearning`
    - `trackLessonView`
  - Updated course fetch logic to return student `progress` and `learningState`.
  - Updated lesson completion to also update learner state.
  - Added routes:
    - `GET /api/courses/continue-learning`
    - `GET /api/courses/:id/learners`
    - `POST /api/courses/:courseId/lessons/:lessonId/view`
- Enrollments:
  - Updated `GET /api/enrollments/my-courses` response to include:
    - `progress`
    - `learningState.lastLessonId`
    - `learningState.nextLesson`
- Certificates:
  - Added `CertificatesService.getCertificate`
  - Added `CertificatesService.verifyCertificate`
  - Added protected route:
    - `GET /api/certificates/:id`
  - Added public route/controller:
    - `GET /api/certificate-verification/:certificateNumber`
  - Reordered certificate controller routes so course status route is not shadowed by `:id`.
